## Utilização
Para executar os testes aqui contidos, é necessário ter instalado na sua máquina o Visual Studio (Recomendado 2022 ou posterior), e o SDK do .NET 10

Passo a passo:

1. Clonar Repositório
2. Abrir a solução usando o Visual Studio
3. Restaurar os pacotes do NuGet, usando o comando `dotnet restore`
4. No menu superior: Teste > Gerenciador de Testes (Atalho: Ctrl + E, T)
5. Executar os testes clicando no botão de executar
